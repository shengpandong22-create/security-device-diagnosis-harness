# Security Diagnosis 评测数据集

该目录是 Phase 7 的受治理评测数据，不替代 `samples/` 中用于功能回归的固定样例。

## 目录约束

- 每个版本独立目录，使用语义版本号；
- `dev` 用于日常开发，标签可见；
- `validation` 用于版本选择和阈值验证，不用于编写个案规则；
- `test` 只允许发布门禁通过 `allow_test=True` 显式读取；
- 三个集合不得复用 `case_id`、`template_group_id`、来源记录或同域近重复事实；
- 每个文件都由 split manifest 的 SHA-256 固定，任何修改必须升级清单并记录 Changelog。

## 安全边界

只允许提交脱敏、人工评审过的合成或授权数据。真实设备 IP、账号、密码、Token、人脸、车牌、卡号和人员标识不得进入仓库。当前 `1.0.0` 仅有 6 个协议基线案例，不能用于宣称生产准确率。

Phase 8D 的发布器要求完整的双人盲标与独立裁决证明、来源授权谱系、同域近重复检查和更高语义版本。固定发布脚本只在临时目录验证 `1.1.0` 候选，不会自动修改本目录；正式扩容仍需人工审核发布内容后单独提交。

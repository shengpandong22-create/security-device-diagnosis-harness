# 高频问题与分层答案

## 1. 为什么不用 LangGraph 等框架？

**30 秒：** 项目目标是研究可信边界，不是展示框架 API。自建最小 ToolLoop 能明确控制轮次、工具预算、失败语义、
Evidence 生成和 Case 写入边界，也更容易做确定性测试。

**2 分钟：** 框架能减少编排代码，但不会自动解决设备授权、证据引用、人工确认、CAS 和指标可复算。项目把 Port、
Registry、Runner 和领域状态机拆开，让模型替换、工具替换与业务不变量独立演进。如果以后引入框架，它只能替换
Runner 编排，不应吞掉 Domain 与治理边界。

**深挖：** 对照 [`agent/runner.py`](../../src/security_diagnosis_harness/agent/runner.py) 与
[`tools/registry.py`](../../src/security_diagnosis_harness/tools/registry.py)，说明预算、白名单和失败路径。

## 2. LLM 在系统里真正不可替代的价值是什么？

**30 秒：** 它处理模糊描述、选择调查顺序和组织候选解释；设备事实、可信度门槛和最终确认仍由确定性机制控制。

**2 分钟：** 四类故障可以完全用规则跑固定案例，但真实输入表达多样、工具组合随上下文变化。LLM 适合做柔性规划，
规则适合做安全和业务不变量。系统刻意采用“概率规划 + 确定执行 + 人工终审”。

## 3. Evidence 与日志有什么区别？

**30 秒：** 日志记录系统发生了什么；Evidence 是满足结构、来源、归属和内容哈希要求，可被结论引用的领域事实。

**深挖：** 失败日志可记录 timeout，但不能自动成为“设备离线” Evidence；否则执行故障会污染业务结论。

## 4. 如何防 Prompt Injection 让模型调用危险工具？

**30 秒：** Prompt 不是安全边界。Registry allowlist、ToolRiskLevel、permission、AuthorizationManifest 和只读 Adapter
共同决定可执行能力，即使模型提出越权工具也会被拒绝。

**深挖：** 说明模型只产生 ToolCall；Registry 验证工具名、参数与权限；正式 Runtime 显式传最小 allowlist。

## 5. 乐观锁为什么比数据库事务还需要？

**30 秒：** 单次事务保证原子性，但两个请求先后读取同一旧版本再分别提交，仍可能发生 lost update。CAS 把读取版本
写进 UPDATE 条件，显式检测陈旧副本。

**2 分钟：** `WHERE id=? AND version=?` + `rowcount` 分类；冲突后返回 409，不自动重放 Agent/HumanReview。

## 6. RAG 如何避免垃圾进垃圾出？

**30 秒：** confirmed Case 只生成 candidate 知识，必须再经 KnowledgeReview；Repository 与 Retriever 只召回 confirmed，
retired 保留历史但退出检索。

**深挖：** 讨论来源 Evidence、状态治理、脱敏、fault_type 过滤及 BGE 失败降级。

## 7. 为什么 Hybrid 的离线结果未必比 Keyword 高？

**30 秒：** 小数据集、Fake embedding 和领域词精确匹配会让 Keyword 很强；这恰好说明不能因为用了向量就宣称提升。

**2 分钟：** 分析 query 分布、embedding 质量、融合权重与 Recall@K；保留基线，以真实 BGE 独立评测决定是否默认启用。

## 8. 评测如何避免“改答案迎合模型”？

**30 秒：** 模型只看候选枚举，不看标准答案；输出严格枚举校验。语义等价但不匹配的案例进入人工争议复核，不自动
修改数据集。

**深挖：** 数据集版本、review decision、grader 版本和 release manifest 共同形成可追溯变更。

## 9. 真机只测一台，有什么价值？

**30 秒：** 它不能证明兼容性规模，但能证伪“整个协议链只在模拟器工作”，并暴露 HTTP 400、Digest 401、RTSP
无 qop 等真实兼容问题。

**2 分钟：** Simulator 覆盖故障矩阵，真机覆盖协议真实性，两者证据互补而不混算。

## 10. 项目这么大，哪些是你真正掌握的？

**30 秒：** 我重点掌握六条链：诊断、确认、设备、持久化、RAG、评测。每条都能从入口讲到失败路径、测试证据与边界。

**回答纪律：** 不按 Phase 罗列文件，不以“测试很多”代替设计解释。主动邀请面试官选择一条深入。

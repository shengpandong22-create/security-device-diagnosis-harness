# 最终简历项目描述

## 推荐项目名

**可信安防设备诊断 Agent Harness**

## 一句话简介

面向摄像头、录像、门禁和报警场景，设计并实现一个受约束、可追溯、可评测的诊断 Agent 工程基座。

## 简历版（推荐）

> 设计并实现可信安防设备诊断 Agent Harness，将 LLM 限制在只读工具、Evidence 引用校验和人工确认边界内；
> 覆盖摄像头黑屏、录像缺失、门禁刷卡异常、报警误报，使用 Simulator 与故障注入建立可重复评测，并在一台
> 授权 Wi-Fi 摄像头上完成 ONVIF/RTSP Digest 最小只读协议闭环。

职责与成果可写为：

- 采用 Ports & Adapters 分离领域、Agent、设备协议和持久化，构建 ToolLoop、Tool Registry、DeviceGateway 与
  Evidence/CitationPolicy/HumanReview 可信链路；
- 设计诊断状态机、跨故障域不变量、深层脱敏、SQLite/Alembic、CAS 乐观锁、追加式审计、一致性扫描及备份恢复；
- 建立版本化数据集、代码 grader、失败归因、历史对比和 Release Gate，区分 Fake、Simulator、真实模型与授权真机证据；
- 构建受治理知识沉淀与 Keyword/BGE/Hybrid 检索，确保只有人工确认知识可召回，现场事实与 SOP 证据分级引用。

## 30 秒口述版

“这个项目不是让模型自由操作设备，而是把模型放进一个可控 Harness。模型只能选择只读工具并给候选结论，
工具成功结果转成 Evidence，CitationPolicy 校验证据强度，最终 confirmed 只能由人工 Review 产生。工程侧还补了
SQLite 持久化、乐观锁、审计、RAG 治理和版本化评测。大部分能力用 Simulator 做确定性回归，最后在一台授权
Wi-Fi 摄像头上验证了 ONVIF 与 RTSP Digest 的最小只读协议链。”

## 诚实边界

可以说：

- 个人工程/学习型工程，完整实现并验证核心可信边界；
- 授权单设备、指定只读协议闭环成功；
- 固定评测用于版本回归；
- Simulator 用于网络与业务异常注入。

不要说：

- 已在公司生产上线；
- 已适配大量品牌或真实设备群；
- 固定 5 条/2 条案例等价于线上准确率；
- Simulator 结果等价于真机联调；
- 系统已经无人值守自主确认故障。

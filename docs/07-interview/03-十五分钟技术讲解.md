# 十五分钟技术讲解

## 时间分配

| 时间 | 内容 | 一句话目标 |
| --- | --- | --- |
| 0—2 分钟 | 场景与风险 | 解释为什么普通 Tool Calling 不够 |
| 2—5 分钟 | 诊断可信链 | 模型建议与业务事实分离 |
| 5—7 分钟 | 设备接入 | 资产、授权、只读和协议边界 |
| 7—9 分钟 | 持久化与并发 | 不泄密、不丢更新、可审计 |
| 9—11 分钟 | RAG 治理 | confirmed-only，现场事实与 SOP 分级 |
| 11—13 分钟 | 评测发布 | 指标可复算、来源不混算 |
| 13—15 分钟 | 真机证据与边界 | 诚实收口，邀请深挖 |

## 一张白板图

```text
User/API
   │
Application ── State/CAS/Audit
   │
ToolLoop ── LLM(candidate only)
   │
Registry ── allowlist/read-only
   │
Routed Gateway ── Asset/Capability/Auth/Budget
   │
Adapter ── Simulator or ONVIF/RTSP
   │
Evidence ── CitationPolicy ── HumanReview
   │
Confirmed Case ── Knowledge Governance ── Hybrid RAG
   │
Versioned Eval ── Attribution/History/Release Gate
```

## 每段必须讲出的证据

1. **可信链**：工具失败 `evidence_drafts=[]`；跨 fault_type 被拒；模型无 confirmed 类型。
2. **设备**：真机只读 Digest 闭环；没有写操作；Simulator 与真机报告分开。
3. **持久化**：两个 stale copy，A 成功到 version 2，B 冲突，赢家数据不被覆盖。
4. **RAG**：candidate/rejected/retired 不召回；Fake 与 BGE 指标分开。
5. **评测**：macro-F1 和引用合规从逐案例复算；不可得 token 是 null。

## 主动暴露的限制

- 单台授权设备、单型号验证，不能外推多厂商；
- 固定数据集规模有限，是回归基线而非线上准确率；
- SQLite 是单机工程基线，不代表分布式高可用；
- LLM 负责候选和工具规划，关键业务结论仍由确定性规则与人工负责。

主动说清限制不会减分，反而证明你理解证据强度。

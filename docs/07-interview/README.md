## 推荐突击顺序

- 第一天：背熟 30 秒和 3 分钟版本，画诊断闭环。
- 第二天：走读 Case、Runner、Registry、Router、Repository。
- 第三天：口述高频题，重点练压力质疑和边界表达。
- 面试前：随机抽一条学习链，2 分钟讲清“问题—设计—证据—限制”。

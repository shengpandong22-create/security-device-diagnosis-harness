# Phase 7 验收标准

## 1. Phase 7A 数据集

- [ ] Dev / Validation / Test 物理隔离
- [ ] 近重复与同源模板不会跨集合
- [ ] 案例包含期望结果、证据、工具、禁止行为和预算
- [ ] 数据集具有稳定版本和变更记录

## 2. Phase 7B Grader

- [ ] 端到端与步骤级指标均可计算
- [ ] 权限、敏感信息、confirmed 越权由代码规则判定
- [ ] 工具选择、参数、重复调用和 Evidence 链可评分
- [ ] Grader 自身有正反例测试

## 3. Phase 7C 版本门禁

- [ ] 报告绑定 commit、数据集、模型、Prompt hash 和配置
- [ ] candidate 与 baseline 保持单变量比较
- [ ] 输出逐案例新增失败与已修复问题
- [ ] 任一 P0 失败阻塞发布
- [ ] 核心指标退化超过容差时进程返回非零

## 4. Phase 7D 真实模型与人工复核

- [ ] 真实模型输入经过脱敏与字段白名单
- [ ] 调用次数、超时、token 和成本受预算限制
- [ ] 真实模型报告与 Fake 基线明确分离
- [ ] disputed 案例经过人工复核才能进入正式数据集

## 5. 总体验收

- [ ] 能回答一次版本变更修复了什么、退化了什么
- [ ] 评测失败能够定位到规则、工具、Evidence、模型或检索阶段
- [ ] 固定案例满分不再被描述为生产准确率
- [ ] 不泄漏真实设备数据、凭证和模型密钥

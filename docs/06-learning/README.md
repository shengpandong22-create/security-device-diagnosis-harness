## 推荐学习节奏

- 第 1 遍：只看图和“绝不能误解”，建立边界。
- 第 2 遍：逐个点击代码索引，用调试器或测试跟一次链路。
- 第 3 遍：不看答案口述追问，每题控制在 2 分钟。
- 第 4 遍：切换到 [`docs/07-interview`](../07-interview/README.md)，练习从简历表述自然展开，而不是背源码目录。
